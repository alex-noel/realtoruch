# Feature status

As of 12 November 2026, the candidate covers rental aggregation, discovery and first-party advertising.

| Area | Implemented and exercised | Remaining evidence or scope |
| --- | --- | --- |
| Collection and source status | Fenced collector leases, bounded retries and rechecks, conditional fetches, and city-scoped freshness and failure states. Access failures, parser drift and missing search results preserve prior observations. Explicit removal evidence can mark a source inactive, and stale records can become unknown. [Connector guide](source-connectors.md) · [Source status checks](verification/T19-handoff.md) | Wider provider and geography coverage, live removal evidence and monitoring. The cloud collector does not populate the local SQL run history. |
| Live source coverage | Earlier bounded Kraków and Warszawa samples exercised Otodom, Gratka and Morizon. The separate T07 soak started on 11 November at 21:27 UTC on pin `b3782cc`, with a fixed 14 November 21:27 UTC target. Gratka failed discovery on that pin. Candidate `3db8927` recovered supported results from a saved capture offline. [Soak evidence](verification/collection-soak.md) · [Gratka replay](verification/T05-handoff.md#gratka-mixed-results-correction-for-t05-and-t07) | The 72-hour gate is incomplete. The pin predates the Gratka correction and other candidate changes. Live Gratka success on the corrected parser remains unverified. |
| OLX and feeds | OLX public-page parsing and explicit imports, plus configurable feed and JSON-LD adapters and an access preflight. Automated OLX HTTP collection is disabled after 403 responses. [OLX handoff](verification/T06-handoff.md) | A permitted automated transport or authorized feed with live access and removal evidence. |
| Canonical homes and saved state | Conservative crosspost and repost matching, aliases, and audited moderator merge and split. A same-price repost preserves seen and saved state and stays quiet. A lower-price relist can produce one logical alert. Saved homes retain delisted entries and respect moderator visibility. [Identity evaluation](verification/dedupe-after.md) · [Rental journey](verification/T18-handoff.md) | Reviewed merge/split corrections silently baseline historical prices while preserving already-related genuine pending changes. [Final acceptance and limits](release-readiness.md). The matching corpus is synthetic. |
| Rental filters and fees | City, text, district, property type, rent, area, rooms, amenities, advertiser, commission, risk, sort, bounding box and polygon filters. A rent ceiling can be strict, and the area minimum is inclusive. Direct offers and known zero commission are independent. Unstated charges remain unknown. [Public API guide](public-api.md) | Verification of advertiser ownership, broader building fields and commute, transit or school layers. |
| Public catalog and search | Bounded anonymous endpoints and OpenAPI. SQL validates current eligibility and visibility before REST returns indexed candidates. Revisioned Elasticsearch is a derived projection, and REST can fall back to SQL with degradation metadata. Structured filters and static pagination were checked on real local PostgreSQL and Elasticsearch. [Public contract checks](verification/T12-handoff.md) · [Index convergence](performance/index-convergence.md) | Text relevance may differ by engine. Production host, quotas, reuse terms and support remain operator decisions. |
| Maps, lists and detail | Responsive list and map, galleries, source comparisons, costs and price history. Local Chromium checks covered keyboard dialogs, coordinate-based polygon editing, and primary screens at four widths and 200% text size. [Web verification](verification/T20-handoff.md) | Production map tiles, provider terms, installed-device map checks and broader assistive technology coverage. Floorplans and tours depend on source data. |
| Historical rent | Observation history and city, district and region summaries with sample sizes. Monthly statistics use one active canonical home per month after selecting the latest observation per source. [History method and measurements](performance/history-baseline.md) | Longer real observation history. The series describes advertised rent from the observed catalog. |
| Contact privacy and moderation | Private keyed contact fingerprints and retention controls, explained risk indicators, user reports, audited hide and restore, and first-party advertiser appeals. [Privacy data map](privacy-data-map.md) | Staffed moderation, production retention and key rotation operations, and richer abuse tooling. |
| Accounts and erasure | Separate auth service, verification and recovery links, refresh rotation and replay rejection, browser HttpOnly refresh cookies, native SecureStore and session revocation. Account closure fences stale writes and retries erasure. Users can reauthenticate with a password for a bounded private export. [Session checks](verification/T14-handoff.md) · [Account data checks](verification/T15-handoff.md) | Installed-device sessions and real account email delivery. |
| Rental alerts | Durable inbox, silent baseline for saved searches, logical event deduplication, confirmed email opt-in and unsubscribe, and fenced delivery retries. Local tests used a file mail sink. Optional Web Push and Expo delivery queues are implemented. [Delivery checks](verification/T13-handoff.md) · [Rental journey](verification/T18-handoff.md) | Real sender and inbox delivery, browser and device push, and provider credentials. SMTP can duplicate physical delivery after acceptance if the worker loses its acknowledgement. |
| Owner adverts and private messages | Owner and agency profiles, draft/publish/edit/withdraw, map or coordinate entry, and HTTPS photo links. Private conversations support blocking and retry deduplication. Read cursors advance through displayed incoming messages, so arrivals below the viewport remain unread. [Message API](verification/T16-handoff.md) · [Inbox client](verification/T17-handoff.md) | Managed media uploads, message email, billing and richer advertiser tools. |
| Incoming links and mobile | Allowlisted listing, account and notification links with sign-in resume and safe retry behavior. Browser link flows and iOS and Android JavaScript exports passed. [Link verification](verification/T21-handoff.md) · [Mobile prerequisites](mobile-validation.md) | Installed iOS and Android builds, device checks, signing, restricted map key and HTTPS domain association. |
| Capacity and recovery | The final native ARM64 PostgreSQL and Elasticsearch synthetic capacity profile met its measured targets. Earlier emulated history timings missed the target. Paired SQLite and PostgreSQL backup and restore drills verified resumed erasure. [Capacity profile](performance/catalog-load.md) · [Paired restore](verification/T27-handoff.md) | The capacity result applies to the documented machine, dataset and mixed workload. Cloud SQL recovery and longer availability measurements remain open. |
| Infrastructure and release | Compose, Terraform and Helm passed local configuration checks. Representative database grants, private readiness and metrics were tested locally. Reviewed source commits were pushed to the authorized GitHub branch `codex/core-sprint-2026-11`. [Infrastructure checks](verification/T28-handoff.md) · [Operational runbooks](operations/runbooks.md) | Cloud infrastructure remains undeployed. Container images and web and native apps remain unpublished. Production credentials, IAM and network enforcement, TLS and live recovery need target-environment verification. |

Imported listings link to their original adverts. Labelled demo listings link to portal homepages and use illustrative photos. Sales, new developments, commercial search, editorial and financing tools are outside this rental release.
