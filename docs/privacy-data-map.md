# Account data, closure and export

## Export contract (v1)

`POST /v1/auth/reauthenticate` requires the normal bearer session and JSON `{"password":"..."}`. On success it returns `{"export_token":"...","expires_in":300}`. The signed token has the distinct audience `realtoruch-account-export`, purpose `account_export`, user ID and session ID. It expires after five minutes and cannot act as an ordinary access token. Do not put it in a URL, logs, email or persistent storage.

`GET /v1/me/export` requires the same active normal session and `X-Account-Export-Token`. A missing, expired, wrong-purpose, wrong-user or wrong-session token returns 401. Responses, including errors, use `Cache-Control: no-store`; successful JSON also uses `private`. The versioned JSON includes only the user's profile and preferences, favorites, saved searches, seen records, own adverts and messages sent by that user. Other users are represented only by public reference IDs; received messages, authentication secrets, delivery payloads, tokens and hashes are excluded. A consistent snapshot is capped at 10 MiB encoded UTF-8. If it would exceed this cap, the endpoint returns 413 with `export_too_large` and no partial data. A paginated or job-based export must be designed before such an account can be exported; this task does not provide one.

## Closure and retention

Authentication disables the account and queues a retryable rental cleanup. Rental cleanup atomically records an opaque user-ID tombstone and removes account-owned saved state, delivery payloads, private conversations and profile/advert drafts; public own listings are withdrawn and stripped of personal advert content. The tombstone has no email, password or contact data and is retained indefinitely to reject already-authorized stale requests. Re-registration creates a new random user ID and never inherits this data. Imported market observations and non-account property history remain; minimal moderation/audit records may remain. Existing time-limited backups can contain data until their ordinary expiry. A restored backup with a pending auth deletion must run the retry worker against the restored rentals database before account traffic or notification delivery resumes; the same idempotent cleanup converges without affecting unrelated homes. This is engineering behavior, not a legal compliance certification.
